# agent-hub — твоя агентная система (деплой на InstaPods)

Ассистент-оркестратор в WhatsApp: пишешь ему обычным языком — он ищет товары и поставщиков, собирает клиентов с телефонами, готовит рассылку (с твоим аппрувом), разбирает ответы, пишет и ревьюит код, мониторит цены. Дешёвая модель делает черновую работу, сильная проверяет. Память экономит токены: в контекст идёт только выжимка, факты и последние сообщения.

Без Docker: хостинг — InstaPods (Python-под + Postgres), WhatsApp — Green API (облачный шлюз), расписания — встроенный планировщик.

## Архитектура

- **Green API инстанс №1 (ассистент)** — номер, на который пишешь ты. Команды принимаются только с твоего номера (`OWNER_PHONE`).
- **Green API инстанс №2 (рассыльный, опционально)** — с него уходит аутрич клиентам. Пока не настроен — всё идёт с первого.
- **Под InstaPods (Python/FastAPI + Pydantic AI)** — оркестратор и под-агенты: товары, лиды, рассылка, входящие, код, мониторинг. Внутри же — планировщик (тик рассылки каждые 15 мин, мониторинг цен каждые 6 ч).
- **Postgres на поде** — задачи, диалог, память, лиды, товары, история цен.

## Деплой на InstaPods

Нужен план **Build ($7/мес)** или выше — на нём доступен Postgres.

### 1. Создай под и базу

```bash
instapods pods create agent-hub -p python
instapods services add agent-hub -s postgresql -w
instapods services creds agent-hub -s postgresql
```

(или через дашборд: Create Pod → preset Python → вкладка Services → Install PostgreSQL)

Креды Postgres из последней команды вставишь в `.env` строкой `DATABASE_URL=postgresql://user:pass@localhost:5432/dbname`.

### 2. Заполни конфиг

```powershell
cd C:\Users\emilx\agent-hub
Copy-Item .env.example .env
```

Минимум для старта:

| Переменная | Где взять |
|---|---|
| `OPENROUTER_API_KEY` | https://openrouter.ai/keys (пополни на $5–10) |
| `OWNER_PHONE` | твой номер цифрами: `79991234567` |
| `GREEN_API_ID_INSTANCE`, `GREEN_API_TOKEN` | https://green-api.com → создай инстанс (тариф Developer — бесплатно) |
| `DATABASE_URL` | креды из шага 1 |
| `SERPER_API_KEY` | https://serper.dev — бесплатно, нужен для веб-поиска |
| `TWOGIS_API_KEY` | https://dev.2gis.com — для поиска клиентов (можно позже) |

Файл `secrets/google-service-account.json` уже на месте — впиши свой gmail в `GOOGLE_SHARE_EMAIL`, чтобы таблицы расшаривались на тебя.

### 3. Залей код и запусти

```bash
instapods files sync agent-hub --local C:\Users\emilx\agent-hub
instapods pods reload agent-hub
instapods logs agent-hub -s app
```

`reload` сам ставит зависимости из `requirements.txt` и перезапускает сервис. Приложение слушает порт 8000 — публичный URL пода (`https://agent-hub.<регион>.instapods.app`) уже проксируется на него.

Проверка: открой `https://<твой-под>.instapods.app/health` — должно вернуть `{"ok": true}`.

### 4. Подключи WhatsApp (Green API)

1. В консоли Green API создай инстанс, авторизуй его QR-кодом с телефона, где стоит **номер-ассистент** (не твой основной!).
2. В настройках инстанса укажи:
   - **webhookUrl**: `https://<твой-под>.instapods.app/webhooks/greenapi`
   - **webhookUrlToken**: то же значение, что в `.env` → `GREEN_API_WEBHOOK_TOKEN`
   - Включи **incomingWebhook = yes**.
3. id инстанса и API-токен впиши в `.env` (`GREEN_API_ID_INSTANCE`, `GREEN_API_TOKEN`), снова `files sync` + `pods reload`.

Рассыльный номер (когда дойдёшь до аутрича): второй инстанс Green API с теми же настройками вебхука → `GREEN_API_OUTREACH_*` в `.env`. Вебхук общий — система сама разруливает: твои сообщения идут оркестратору, чужие — в разбор входящих.

### 5. Проверка

Напиши со своего номера на номер-ассистент: «привет». Должен ответить.

## Веб-админка

Задай в `.env` на поде `ADMIN_PASSWORD=<длинный пароль>` и перезапусти под. Открой `https://<под>.instapods.app/admin` (логин `admin`). Там: модели и промпты каждого агента, вкл/выкл инструментов, живые задачи, память (факты/выжимка/архив), лиды, аппрув рассылки, мониторинг, лимиты. Правки применяются сразу, без рестарта.

Полное описание устройства системы — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Модели и расход

Ярусы в `.env`: `MODEL_CHEAP` (черновики, классификация, ~85% вызовов), `MODEL_STRONG` (ревью кода и сообщений). Id моделей — с https://openrouter.ai/models. Если оркестратор плохо понимает команды — впиши в `MODEL_ORCHESTRATOR` сильную модель.

## Лимиты рассылки (важно)

WhatsApp банит за холодную рассылку. Защита в `.env`: `OUTREACH_DAILY_LIMIT=20` (на старте не повышай!), пачки по 2 каждые ~15 мин со случайными задержками. Новый номер первые 1–2 недели «прогревай»: обычные переписки, минимум рассылки. Риск бана рассыльного всё равно есть — поэтому для аутрича лучше завести отдельный второй инстанс, а не слать с ассистента.

## Структура

```
agent-hub/
├── app.py                 # вход для InstaPods (python app.py, порт 8000)
├── requirements.txt
├── secrets/               # google-service-account.json (не в git)
├── data/                  # exports (CSV), code (результаты кодовых задач) — создаётся на поде
└── app/
    ├── main.py            # FastAPI: вебхук Green API, планировщик, ручные тики
    ├── orchestrator.py    # мозг: интент → инструменты → под-агенты
    ├── memory.py          # окно + выжимка + факты + архив (FTS)
    ├── tasks.py           # фоновые задачи + уведомления
    ├── monitoring.py      # мониторинг цен
    ├── schema.sql         # схема БД (накатывается при старте)
    ├── llm.py, config.py, db.py, wa.py
    ├── tools/             # web_search, 2gis, wildberries, scraper, sheets
    └── subagents/         # product, lead, outreach, inbox, code (+ ads потом)
```

## Если что-то не работает

```bash
instapods logs agent-hub -s app        # логи приложения
```

- Ассистент молчит → проверь `OWNER_PHONE` (только цифры, с 7), webhookUrl в консоли Green API, статус инстанса (authorized) и логи.
- WB перестал отдавать товары → у WB иногда меняется версия эндпоинта (`v4` в `app/tools/wildberries.py`), поменяй на актуальную (видно в DevTools на wildberries.ru).
- Таблицы не создаются → проверь `secrets/google-service-account.json` и включённые Sheets+Drive API; без них всё падает в CSV в `data/exports/`.
- После изменения `.env` не забудь `files sync` + `pods reload`.
